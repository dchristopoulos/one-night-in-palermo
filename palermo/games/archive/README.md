# Archive: games from older engines

Everything here was played (or dry-run) on earlier builds of `game.py`, between 2026-10-22 and the round-8 engine of
2026-11-15: timestamp-named single games, six-seat evenings (`run`, `tour`, `reh`, `offa`, `offhv`, `lean*`, ...), the
first demo cuts (`showcase*.json`), test and dry files, the codex-quota games where three seats sat silent
(`quota-silent/`), and the logs and timeout dumps of those runs. The rules, prompts and seat count changed many times
over that period so these games are not comparable with the current
evenings in `games/` and with each other; they are kept for the history and because some notes and the viewer tests
(`ui/src/game.test.ts`) quote them. `view.py` lists only the top level of `games/`, so nothing here shows in the viewer;
open one directly with `?file=games/archive/NAME.json`.
